# Участие в разработке

Спасибо за интерес к проекту. Изменения должны сохранять простоту запуска: Windows PowerShell 5.1, встроенные компоненты Windows и четыре файла для работы утилиты.

## Перед началом

- Проверьте открытые issues, чтобы не дублировать работу.
- Для существенных изменений сначала создайте issue с описанием проблемы и предлагаемого решения.
- Уязвимости не публикуйте в issues. См. [SECURITY.md](SECURITY.md).

## Требования

- Windows 10 или Windows 11;
- Windows PowerShell 5.1;
- видеокарта AMD или NVIDIA для ручной проверки;
- доступ к интернету для запросов к сайтам производителей.

## Рабочий процесс

1. Сделайте fork репозитория и создайте отдельную ветку.
2. Внесите изменения и проверьте их локально.
3. Обновите документацию, если меняется поведение, параметры CLI или требования.
4. Откройте pull request с кратким описанием и шагами проверки.

## Стиль кода

- Совместимость с Windows PowerShell 5.1, без внешних модулей и зависимостей.
- Файлы `.ps1` — UTF-8 с BOM, отступы в четыре пробела.
- Имена функций и параметров — в стиле PowerShell (`Verb-Noun`).
- Не добавляйте секреты, токены, абсолютные пользовательские пути и скачанные драйверы.
- Сохраняйте существующую архитектуру: общая логика в `GpuDriverCore.ps1`, интерфейс в `Get-GpuDriver-GUI.ps1`.
- Для изменений интерфейса приложите скриншот до/после, если это уместно.

## Проверка

Синтаксис:

```powershell
$files = Get-ChildItem -Filter *.ps1 -Recurse -File
foreach ($file in $files) {
    $tokens = $null
    $errors = $null
    [void][System.Management.Automation.Language.Parser]::ParseFile($file.FullName, [ref]$tokens, [ref]$errors)
    if ($errors.Count) { $errors | ForEach-Object { Write-Error "$($file.Name): $($_.Message)" } }
}
```

Статический анализ:

```powershell
Install-Module PSScriptAnalyzer -RequiredVersion 1.22.0 -Scope CurrentUser -Force
Invoke-ScriptAnalyzer -Path . -Recurse -Severity Error
```

Ручные проверки:

```powershell
.\Get-GpuDriver.ps1 -ListGpus
.\Get-GpuDriver.ps1 -DryRun
.\Get-GpuDriver.ps1 -CheckUpdate
Start-GpuDriver.bat
```

Проверьте поиск драйвера, отмену загрузки, проверку подписи и запуск установщика в GUI. Не устанавливайте драйвер на рабочей машине без необходимости.

## Коммиты

- Один коммит должен описывать одно логическое изменение.
- Сообщение — короткое и по существу, на английском или русском языке.
- Не коммитьте журналы, `.part`-файлы, скачанные драйверы и временные скриншоты.
