# История изменений

Все заметные изменения проекта документируются в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.1] - 2026-11-01

### Безопасность

- Загрузки переведены на HTTPS с проверкой домена на каждом редиректе, лимитами размера и времени и случайными временными файлами.
- Перед установкой проверяются точное имя издателя, корневой сертификат в `LocalMachine\Root` и SHA-256; при ошибке файл помещается в карантин.
- Установщик запускается только из отдельной проверенной папки с защитой от подмены; добавлена повторная проверка хэша.
- Добавлены безопасные имена файлов, MOTW, проверка путей и абсолютные пути к системным утилитам.
- CI закрепляет действие checkout и версию PSScriptAnalyzer, проверяет UTF-8 BOM.

## [1.0.0] - 2026-10-31

Первый публичный релиз.

### Добавлено

- Выбор видеокарты в GUI и список адаптеров в CLI (`-ListGpus`).
- Проверка Authenticode-подписи и издателя установщика перед запуском.
- Блокировка неподписанных и чужих файлов с переименованием в `.unverified`.
- Локальный журнал с ротацией, копированием ошибки и открытием журнала из GUI.
- Проверка обновлений через GitHub Releases в GUI и CLI (`-CheckUpdate`).
- Английская документация `README.en.md`.
- GitHub Actions: проверка синтаксиса и PSScriptAnalyzer.
- `CONTRIBUTING.md`, `SECURITY.md`, `.gitattributes` и release-архив с SHA-256.
- Демонстрационный GIF и обновлённые скриншоты.

### Изменено

- Определение GPU переведено на PCI Vendor/Device ID с разбором PnP ID.
- Улучшены сообщения об ошибках и состояния интерфейса.
- README дополнен разделами о журнале, обновлениях и проверке подписи.
- Версия утилиты выводится в заголовке CLI и в правом верхнем углу GUI.

### Безопасность

- Установщик запускается только после успешной проверки подписи и подтверждения пользователя.
- Ссылки по-прежнему ограничены официальными доменами AMD и NVIDIA.
- В журнал не записываются токены и другие секреты.
